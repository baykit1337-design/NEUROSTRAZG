# Скопируйте этот файл в proxies.txt и впишите свои адреса.
# proxies.txt в .gitignore — учётные данные в репозиторий не попадут.
#
# Платные и общие открытые адреса можно держать в одном списке,
# программа разберётся сама. Понимаются все формы:
#
#   ip:port:username:password
#   ip:port                      — открытый, без авторизации
#   username:password@ip:port
#   http://ip:port
#
# Пустые строки и строки с # игнорируются.
# Список можно править на ходу: кнопка «Перезагрузить» в интерфейсе
# или повторный запуск с --proxies, перезапуск программы не нужен.
