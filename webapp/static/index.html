Журнал работы

Вероятно, это одно и то же под разными написаниями. Слияние переносит второе имя в варианты первого.

Принимаются «ключ = значение», JSON, CSV и Markdown — формат определяется по содержимому. Записи считаются подтверждёнными сразу: их писал человек.

Пересказ по главам собирается из уже разобранных фактов — без единого запроса к модели и без выдумки: в нём ровно то, что нашлось в тексте. Аннотация книги — один запрос: связный текст из разрозненных фактов сам не соберётся.

Формат «было = стало», по правилу в строке. Строка с приставкой re: — регулярное выражение. Словарь свой у каждой книги: лежит рядом с ней в replacements.txt.

Главы сопоставляются по номерам. Ничего не исправляется — только показывается, где смотреть.

Глава показывается в том оформлении, в каком уйдёт в файл. Правка пишется поверх исходника — копия уходит в корзину. Читается то, что выбрано в блоке «Что правим» выше.

Опечатки вроде «превет»: правила проверки их не ловят — слово оформлено верно, его просто нет. Работает офлайн. Имена из реестра сущностей подхватываются сами, остальное вносится кнопкой «это имя» — свой словарь книги лежит рядом с ней в spelling.txt. Слово считается известным по морфологии, а не по списку: «усмехнулся» и «длинной» ошибками не считаются.

Несколько операций подряд, без участия человека: разбить → переименовать → проверить. Шаг без своего выбора берёт на вход папку, которую сделал предыдущий, — цепочка складывается сама. При ошибке очередь останавливается: следующий шаг ждёт результата.

Сравнение двух версий одной книги: до операции и после. Сравниваются абзацы, а не байты — перенос строки правкой не считается.

Перед перезаписью старая версия папки копируется в корзину. Хранятся последние копии, старые удаляются сами.

Иероглифы и латиницу не трогаем — их надо смотреть глазами.

Сайт отдаёт только суточный срез: рейтингов «за неделю» и «за месяц» у него нет. Срезы складываются к себе, и движение считается уже по своей истории — видно не просто популярное, а то, что набирает обороты. По расписанию ничего не запрашивается: срез снимается кнопкой.

Каждый эффект отдельный и снимается сам по себе. Со снятыми галочками программа выглядит и работает так же, как без оформления вовсе. Выбор запоминается в браузере.
